# Motor Norte

Web de un concesionario de deportivos en el Poblenou (Barcelona). Es un proyecto de clase: el concesionario es inventado y las fotos son de Unsplash.

## Qué tiene

- Portada con los faros de un coche: el círculo de luz sigue al ratón.
- Tres coches en exposición (Porsche 911 de circuito, BMW M4 Coupé y Audi R8 V10). Las fotos se inclinan en 3D según dónde pongas el ratón.
- Una doble línea amarilla de carretera como separador entre secciones.
- Botón de volver arriba que aparece al empezar a bajar.
- Formulario de contacto de prueba: no envía nada, solo muestra un aviso.
- Horario y datos de contacto.

## Cómo está hecho

HTML, CSS y JavaScript, sin librerías. La tipografía es Barlow, de Google Fonts.

```
index.html      estructura de la página
css/styles.css  estilos
js/main.js      faros, inclinación 3D, botón de subir y formulario
img/            fotos de los coches
```

## Cómo verla

Descarga el repositorio y abre `index.html` en el navegador.
